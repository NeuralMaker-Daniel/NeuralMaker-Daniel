## 🤖 Projeto em destaque | Featured Project

### 🔴 NeuralBots — Robótica e Sistemas Autônomos

Projeto de desenvolvimento de robôs autônomos que integra software, eletrônica, visão computacional e sistemas embarcados.

A equipe participou da competição internacional **FIRA Canada 2026**, conquistando o **3º lugar na categoria Autonomous Cars** e a classificação para a etapa na Malásia.

**Áreas de desenvolvimento:**
- Processamento de imagens e reconhecimento de pista.
- Detecção de obstáculos com visão computacional.
- Controle de direção e motores.
- Integração de sensores e hardware.
- Desenvolvimento de software robótico com ROS 2.
- Simulação e experimentação de sistemas autônomos.
